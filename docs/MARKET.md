# 市场提交信息

| 字段 | 内容 |
|---|---|

| 插件名 | `astrbot_plugin_memory_post` |
| 显示名 | 鲸语拾光 · 记忆说说 |
| 短描述 | 用她自己的记忆，每天写一条 QQ 空间说说 |
| 作者 | 大肥鱼 |
| 版本 | 0.5.0 |
| 最低 AstrBot | >=4.17.0 |
| 支持平台 | aiocqhttp / qq_official / qq_official_webhook |
| 标签 | QQ空间、记忆、说说 |
| 图标 | 暂无（可选） |

长描述：

> 从记忆与日记里挑素材，用她的人格写一条说说，发布前先过隐私过滤和文本检查。
> 默认草稿模式，可切自动；发布支持 qzone_ultra daemon 或自带的 qzone_native（Cookie 直连，不依赖 AstrBot），也可以只写 outbox。
> 核心与平台无关，CLI / MCP / HTTP 也能单独跑。

## 提交步骤

1. https://cloud.astrbot.app 用 GitHub 登录
2. 提交插件，填仓库地址并授权
3. 等 Cloud 构建 v0.1.0
4. 审核通过后市场可搜「记忆说说」
